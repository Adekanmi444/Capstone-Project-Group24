# Frontend Capstone Project - Group 24

Welcome to the **Group 24 Capstone Project Repository**.

This project was developed by Group 24 as part of our Frontend Development Capstone Project. The purpose of this project is to apply the skills learned in HTML, CSS, JavaScript, React, Git, and GitHub while collaborating as a team to build a responsive and user-friendly website.

This repository serves as the central location for project development, documentation, collaboration, and progress tracking.

---

## Live Demo

**Deployment Link:** https://capstoneprojectgroup24.vercel.app/

---

## Project Overview

This project is a frontend web application designed to demonstrate our understanding of modern web development principles.

The project focuses on:

* Responsive web design
* Clean and accessible user interfaces
* Team collaboration using Git and GitHub
* Real-world project development workflow

---

## Project Objectives

* Build a fully responsive website.
* Apply HTML, CSS, and JavaScript concepts learned during training in a real project.
* Practice teamwork and collaboration.
* Practice component-based development.
* Learn industry-standard Git and GitHub workflows.
* Improve problem-solving and debugging skills.
* Develop responsive and accessible user interfaces.
* Deliver a polished frontend project.

## Team Rules

* Do not push directly to the main branch.
* Always work on a separate branch.
* Pull updates before starting work.
* Write meaningful commit messages.
* Test your code before pushing.
* Respect feedback during code reviews.
* Communicate issues early.

## Project Documentation

### Design Decisions

* Consistent typography and color scheme.
* Responsive layouts using Flexbox and CSS Grid.

### Challenges Encountered

* Merge conflicts during collaboration.
* Layout issues on smaller screens.
* Image optimization challenges.

### Solutions Implemented

* Improved branch management.
* Added media queries for responsiveness.
* Optimized image sizes.
* Conducted cross-browser testing.
